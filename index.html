Guía de Uso Rápido • ID-TIC

Paso a paso para gestionar los equipos del centro y cumplir tus indicadores de desempeño.

Paso 1

Registrar Equipos

Haz clic en "Nuevo Equipo". Introduce el ID del equipo (ej: TIC-2026-001), tipo, marca, número de serie del fabricante, ubicación actual y estado operativo.

Paso 2

Imprimir Pegatinas QR

Ve a la pestaña "Etiquetas QR". Verás la lista de códigos QR generados automáticamente para cada ID. Haz clic en "Imprimir Plancha de QR" e imprímelos en papel adhesivo para pegarlos en las laptops, proyectores o pantallas.

Paso 3

Escanear desde tu Celular

Presiona el botón superior "Escanear QR". Apunta con la cámara del teléfono a la etiqueta pegada en el equipo para buscarlo inmediatamente y cambiar su estado o ubicación en segundos.

Paso 4

Reportes para Septiembre y Junio

En la pestaña "Reporte Oficial", el sistema organiza los datos con la cabecera oficial del MINERD/Distrito 07-06 y el formato requerido para la firma del Director Juan Ramón Paulino Balbi.

Guarda tus datos sin perder nada

Tus datos se guardan en tu celular/PC. También puedes conectar Supabase en el botón de la barra superior para sincronizar en la nube.

Selector de Modelos de Portada Institucional

Elige entre 4 diseños profesionales adaptados para los informes y portafolios del MINERD y SISMAP.

Despliegue Rápido en GitHub Pages

Sigue estos sencillos pasos para subir tu aplicación de inventario a GitHub y tenerla disponible en la nube accesible desde cualquier celular.

1

Crea un Repositorio en GitHub

Entra a github.com, crea un nuevo repositorio público llamado dinamizador-tic-pro.

2

Guarda este archivo como index.html

Copia el código completo de esta aplicación y guárdalo exactamente con el nombre index.html.

3

Sube el archivo a tu repositorio

Sube el archivo index.html mediante la interfaz web de GitHub ("Add file > Upload files") o por terminal:

git init
git add index.html
git commit -m "Deploy Dinamizador TIC Pro"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/dinamizador-tic-pro.git
git push -u origin main
4

Activa GitHub Pages

Ve a la pestaña Settings de tu repositorio en GitHub > Pages > En SIS/Branch selecciona main y carpeta / (root). ¡Listo! Tu app estará en línea con URL pública.

Ver Script SQL para crear la tabla en Supabase 
CREATE TABLE IF NOT EXISTS equipos (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  asset_id TEXT UNIQUE NOT NULL,
  tipo TEXT NOT NULL,
  marca TEXT,
  serie TEXT,
  ubicacion TEXT NOT NULL,
  estado TEXT NOT NULL,
  notas TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
